# Project Status & Roadmap

Current state, supported features, and technical notes for `astro-starter`.

## Implemented Scope

- **Astro 7 Core**: Zero-JS static site generation with extreme performance.
- **Tailwind CSS v4**: Modern `@tailwindcss/vite` integration.
- **Atomic Components**: Modular structure with `SpotlightCard`, `TechStackCard`, and `TheExample`.
- **Linting & Code Quality**: Configured with `@antfu/eslint-config` and `eslint-plugin-astro`.

## Roadmap

- [ ] Markdown / MDX content collections integration.
- [ ] SEO, Sitemap, and RSS feed integrations.
- [ ] GitHub Actions CI workflow for build and lint validation.
